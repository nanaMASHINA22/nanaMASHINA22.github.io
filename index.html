Папка скриптов
Справочник MS-ES1

Основы

clockspeed <value> — устанавливает количество инструкций, обрабатываемых за тик.

splitter <value> — текст-разделитель для команды split (поддерживает замену переменных).

endtick — игнорирует скорость обработки и приостанавливает AUTOCAL до следующего игрового тика.

shutdown — отключает питание AUTOCAL, мгновенно завершая программу.

Управление памятью

buffer <value> — сохраняет указанное значение в буфер.

save <var> — сохраняет содержимое буфера в переменную с указанным именем.

load <var> — записывает значение указанной переменной в буфер.

concat <value> — добавляет значение в конец буфера, позволяя объединять несколько значений (поддерживает замену переменных).

push [value] — записывает указанное значение или буфер в стек (поддерживает замену переменных).

pop — извлекает значение из стека и записывает его в буфер.

peek — записывает значение из стека в буфер, не изменяя стек.

Управление текстом

first <num> — записывает в буфер первые num символов буфера.

last <num> — записывает в буфер последние num символов буфера.

length — подсчитывает количество символов в буфере и записывает результат в буфер.

split <index> — делит буфер по splitter и записывает в буфер фрагмент с указанным номером (начиная с 1).

splitcount — делит буфер по splitter и записывает в буфер количество фрагментов.

Вычисления

eval [expression] — вычисляет математическое выражение и сохраняет результат в буфер (поддерживает замену переменных).

evalr [expression] — вычисляет математическое выражение и сохраняет округлённый результат в буфер.

round / nearest — округляет содержимое буфера до ближайшего целого.

rounddown / floor — округляет содержимое буфера в меньшую сторону.

roundup / ceil — округляет содержимое буфера в большую сторону.

worldtime — сохраняет в буфере количество тиков с момента создания мира.

Сравнение (параметр vs буфер)

eq <value> — записывает true в буфер, если значение равно содержимому буфера (поддерживает замену переменных).

gtb <value> — записывает true в буфер, если выполняется условие «больше, чем буфер» (поддерживает замену переменных).

ltb <value> — записывает true в буфер, если выполняется условие «меньше, чем буфер» (поддерживает замену переменных).

geb <value> — записывает true в буфер, если выполняется условие «больше или равен буферу» (поддерживает замену переменных).

leb <value> — записывает true в буфер, если выполняется условие «меньше или равен буферу» (поддерживает замену переменных).

Переходы

dest <name> — создаёт пункт назначения для прыжка с указанным именем.

jmp <dest> — выполняет безусловный переход к пункту назначения (поддерживает замену переменных).

jmpif <dest> — переходит к пункту назначения, если содержимое буфера истинно (поддерживает замену переменных).

jmpnot <dest> — переходит к пункту назначения, если содержимое буфера ложно (поддерживает замену переменных).

Редстоун-по-Радио

send <channel> — отправляет содержимое буфера в виде сигнала РпР по указанному каналу (поддерживает замену переменных).

listen <channel> — принимает последний сигнал РпР по указанному каналу и записывает его в буфер (поддерживает замену переменных).

poll <channel> — принимает текущий сигнал РпР по указанному каналу (с последнего игрового тика) и записывает его в буфер (поддерживает замену переменных).

Терминал РпР

Позволяет сохранять значения в виртуальную память по ID канала. В основном коде вы можете забрать эти значения командой listen <ID> или poll <ID>.

chan <ID> — выбрать канал (ID) для работы.

send <value> — сохранить значение в выбранный канал.

start <value> — аналог send (сохранить значение).

stop — удалить значение из выбранного канала.

clear — очистить весь лог терминала.
